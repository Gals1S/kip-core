# Памятка арбитру

## Зачем этот файл

Этот файл — для человека. Чатам он не передаётся.

Обычно работу ведёт управляющий чат: ставит задачи, проверяет
результаты, говорит, что делать дальше. Памятка нужна, когда чата нет
(достигнут лимит, чат закрылся, начинаете с нуля), а также для
настройки инструментов и ведения сессии.

Проверять результаты, искать конфликты, решать технические вопросы —
работа чата. Задача арбитра — передать контекст и запустить работу.

## Разделы памятки

1. Подготовка среды разработки.
2. Средства разработки.
3. Создание нового чата.
4. Ведение сессии.

## 1. Подготовка среды разработки

Инструменты одинаковы для всех проектов экосистемы (handover,
раздел 8). Установить один раз.

### VS Code

1. Скачать с `code.visualstudio.com` и установить.
2. Открыть VS Code, нажать `Ctrl + Shift + X` (панель расширений).
3. Найти и установить два расширения:
   - **Markdown All in One** (автор Yu Zhang);
   - **Markdown Preview Enhanced** (автор Yiyi Wang).

### Git

1. Скачать с `git-scm.com` и установить (настройки по умолчанию).
2. Проверить: открыть терминал в VS Code (`Ctrl + ~`) и ввести
   `git --version`. Должна появиться версия.

### Total Commander

1. Скачать с `ghisler.com` и установить.
2. Используется вместо Проводника Windows: копирование файлов,
   сборка пакета для чата.

### Проверка

Всё установлено, если:
- VS Code открывает папку проекта и показывает файлы;
- в терминале VS Code работает `git --version`;
- Total Commander открывает папку проекта.

## 2. Средства разработки

### Открыть проект

VS Code → `File` → `Open Folder` → папка проекта (например,
`D:\A\Projects\KIP_Core`). Слева появится дерево файлов.

Терминал открывается в VS Code: `Ctrl + ~`. Он открывается уже
в папке проекта — переходить никуда не нужно.

### Прочитать или поправить документ

Файлы `.md` открываются в VS Code двойным щелчком в дереве слева.
Предпросмотр — `Ctrl + Shift + V` (Markdown Preview Enhanced).

### Коммит

Формат сообщения коммита — `ДД.ММ.ГГГГ: что сделано`
(пример: `08.11.2026: ADR-010, ADR-011 — состав экосистемы и поток данных`).

В терминале VS Code:

```powershell
git add .
git commit -m "08.11.2026: что сделано"
```

`git add .` — добавить все изменения; `git commit -m "..."` —
зафиксировать с сообщением.

### Собрать пакет файлов для чата

1. Открыть Total Commander.
2. Перейти в папку проекта.
3. Выделить нужные файлы (по перечню из сценария — раздел 3).
4. Перетащить их в окно чата или приложить через кнопку вложения.

### Создать папку для нового чата

В Total Commander: `F7` → ввести имя папки (например, `register`) →
`Enter`. Папка создаётся в текущем каталоге — проверьте, что вы
в корне проекта.

## 3. Создание нового чата

Файлы хранятся в проекте, к которому относятся; правила размещения
и имён — в `handover.md`, раздел 5. Ниже — что приложить.

Два случая: чат открывается по заданию (работа начинается с нуля)
и чат восстанавливается после лимита (работа продолжается).

### 3.1. Управляющий чат Core

Приложить:

1. `SPECIFICATION.md`
2. `handover.md`
3. `CORE-ARCH-data-model.md`
4. `CORE-ARCH-data-flow.md`
5. Последний дневник из `diary/` — файл с самой поздней датой
   (`ГГГГ-ММ-ДД-diary.md`)

Текст:

    Проект KIP_Core. Это управляющий чат Core.
    Прикладываю SPEC, handover, архитектурные документы и последний
    дневник. Продолжаем с места остановки.

### 3.2. Ресерч-чат

Приложить:

1. `SPECIFICATION.md`
2. `handover.md`
3. `templates/CORE-RSH-template.md` — шаблон отчёта
4. Файл задания из `research/` (`CORE-RSH-REQUEST-NNN-<тема>.md`)
5. `decisions/CORE-ADR-REGISTRY.md` — реестр ADR
6. Существующие исследования по теме из `research/` — если есть

Текст:

    Проект KIP_Core. Это ресерч-чат по заданию управляющего чата Core.
    Прикладываю задание, шаблон отчёта, SPEC, handover и реестр ADR.
    Результат — файл исследования в research/.

### 3.3. Управляющий чат утилиты

Приложить:

**Из Core:**
1. `SPECIFICATION.md`
2. `handover.md`
3. `CORE-ARCH-data-model.md`
4. `CORE-ARCH-data-flow.md`
5. `decisions/CORE-ADR-REGISTRY.md`

**Из утилиты:**
6. `<UTIL>-SPEC.md`
7. `handover.md` утилиты
8. `<UTIL>-ADR-REGISTRY.md` — реестр ADR утилиты
9. Последний дневник утилиты

Текст:

    Проект KIP_<утилита> (утилита экосистемы KIP_Core).
    Это управляющий чат утилиты. Прикладываю документы Core
    и документы утилиты. Продолжаем с места остановки.

### 3.4. Задачный и отладочный чаты

Приложить:

1. Файл задания (`CORE-TASK-NNN-<тема>.md`)
2. `templates/CORE-HANDOFF-template.md` — шаблон отчёта
3. Документы, которые указал управляющий чат Core в задании

Текст:

    Проект KIP_<утилита>. Это задачный чат по заданию управляющего
    чата Core. Прикладываю задание и шаблон отчёта.
    Результат — отчёт о завершении.

## 4. Ведение сессии

### Начало сессии

Написать чату дату и время начала:

    Сегодня 08.11.2026, сейчас 11:35, продолжаем.

Чат задаст первый вопрос по открытому пункту.

### Во время сессии

- Работа идёт мелкими шагами: чат предлагает — вы отвечаете.
- Новые мысли сразу пишите чату, сами ничего не записывайте.
- Когда чат формирует документ — скопируйте его в файл. Это
  естественная остановка: дальше чат не идёт, пока вы не примете
  или не дадите замечания.
- Если чат выдал больше одного вопроса — скажите «два», он разделит.

### Конец сессии

Сообщить чату время окончания:

    Сейчас 22:46, закрываем сессию.

Чат сформирует дневник. Сохранить его в проект, где шла сессия.

Если сессия не закончена, а вы уходите — всё равно сообщите время:
дневник зафиксирует, где остановились.

### Куда сохранять

Файл сохраняется в проект, к которому относится. Правила размещения
и имён — в `handover.md`, раздел 5.
