# CORE-ADR-015: Неизменяемость состава сигналов у шаблона модели при использовании

**Проект:** KIP_Core
**Статус:** см. `decisions/CORE-ADR-REGISTRY.md`
**Дата:** 15.11.2026
**Связанные документы:** `REG-REQ-007`, `CORE-ARCH-data-model.md`

## Контекст
В модели данных **Проектный стандарт** (`project_standard`) — это шаблон, который задает жесткий состав сигналов для **конкретной модели прибора** (например, для модели «Метран-150» на этом проекте). Если позволить менять этот состав, когда на шаблон уже ссылаются приборы, возникает риск потери данных или сложных каскадных пересчетов.

## Решение
1. **Запрет изменения состава:** Запрещено изменять состав сигналов (`project_standard_signal`) у шаблона модели, если к нему привязан хотя бы один прибор. При попытке API возвращает `409 Conflict`.
2. **Разрешенные изменения:** Изменять название шаблона или значения по умолчанию (характеристики) можно в любое время.
3. **Как менять состав:** Если инженеру нужно изменить состав сигналов для этой модели, он должен создать новый шаблон (стандарт) с нужным составом и перевести приборы на него.

## Последствия
- **Положительные:** Значительное упрощение кода. Защита от потери переопределений у приборов.
- **Отрицательные:** Пользователю придется выполнить чуть больше действий для изменения состава (создать новый стандарт).
