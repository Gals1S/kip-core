# Реестр ADR проекта KIP_Core

> **Назначение:** единая точка, где видно, какие ADR действуют, какие изменены, какие заменены.
> **Класс:** B (живой) — правится при выпуске нового ADR, см. `docs/handover.md`, раздел 5.
> **Источник правды:** сам ADR. При расхождении реестра с текстом ADR — прав ADR, реестр исправляется.
> **Передача ADR:** ADR передаётся только вместе с этим реестром — иначе получатель не увидит, что ADR заменён или изменён.

---

## Статусы

| Статус | Значение |
|---|---|
| **Действует** | ADR актуален, применяется без изменений |
| **Действует с изменениями** | ADR актуален, но его отдельные разделы изменены другим ADR (указан в колонке «Изменяет / Заменяет») |
| **Заменён** | ADR полностью утратил силу; действует ADR, указанный в колонке «Изменяет / Заменяет» |

## Правила ведения реестра

- **При выпуске нового ADR** — добавить строку в таблицу, проставить статусы затронутых ADR (для них — «Действует с изменениями» или «Заменён» с указанием номера).
- **Текст ADR не правится** (класс A, append-only). Статус в ADR — ссылка на этот реестр, а не значение.
- **Реестр — не источник правды.** Если реестр противоречит ADR, прав ADR; реестр приводится в соответствие.
- **При передаче ADR** (в новый чат, в письмо) — прикладывать этот реестр вместе с ADR.
