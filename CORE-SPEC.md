# KIP Core — Спецификация экосистемы

Экосистема KIP Core обеспечивает полный цикл работы с данными контрольно-измерительных приборов (КИП) для судостроения.

## Функции экосистемы

1. **Извлечение данных** — первичный импорт и чтение информации из принципиальных схем.
2. **Учёт и обогащение** — централизованное хранение, верификация по справочникам и ручное дополнение информации пользователем.
3. **Формирование выходных документов** — генерация табличных и векторных отчетов на основе накопленных и проверенных данных.

## Требования к целевой среде эксплуатации
Итоговое программное обеспечение экосистемы должно функционировать в следующих условиях (ограничения не распространяются на среду разработки и процесс создания ПО):
- Целевая ОС: Windows 10/11 x64.
- Запуск без прав администратора.
- Работа без доступа в интернет (все ресурсы локальные, без CDN и внешних сервисов).
- Портативность: перенос на другой ПК простым копированием папки (без установки).
- Ориентир на коллективную работу: до 10 пользователей с единой версией пакета и общей базой данных по локальной сети.

## Форматы обмена

- Обмен данными между функциональными блоками экосистемы происходит через файлы. Прямое API-взаимодействие между независимыми блоками не предполагается.
- Конкретные форматы файлов, их кодировка и структура определяются на этапе реализации, но должны строго опираться на единую модель данных.
